# Paper 3 — Draft v0.6.2

*(DOFT-only scaling + testable bridge to vortex matter in type-II superconductors)*

## Title
**Coherence, Topology, and Memory in DOFT Oscillator Networks: Scaling Laws and Testable Links to Vortex Matter in Type-II Superconductors**

## Author
**C. Agostino** — Independent Researcher, Buenos Aires, Argentina

## Abstract
Delayed-Oscillator Field Theory (DOFT) models stable structure emerging from networks of coupled oscillators with finite delay and internal memory. We treat DOFT as a speculative but testable constraint-based program. In prior work we reported (i) prime-space “fingerprints” generated by a delayed-locking grammar plus a minimal correction law, and (ii) integer-participation structure under structural noise via a mother-frequency observable—both extracted from superconducting materials datasets. Here we shift from phenomenological mappings to a DOFT-only simulation program designed to probe how coherent structure scales with network size N and topology.

We introduce an Ola sequential multistage pipeline (Ola1–Ola4) that separates candidate search from dynamical measurement: a fast Explorer proposes and filters candidate network instances to manage combinatorial growth, while a multicore Sweep integrates the governing coupled differential dynamics (ODE-based measurement) and computes late-time observables. Three robust findings organize the results: (1) mean lock coherence decreases monotonically with network size, consistent over the explored range with a geometric decay close to R ∝ N⁻¹ᐟ³ (also compatible with exponential relaxation toward a finite floor); (2) at larger N, surviving outcomes exhibit high participation of a distinct memory layer (S2), suggesting memory acts as stability overhead under geometric stress; (3) topology becomes increasingly selective with N, with a transition region (N ≈ 6–9) culminating in an apparent monolithic ceiling at N ≈ 8–9 for single-module templates where survival rates collapse.

These scaling patterns parallel phenomenology of vortex matter in type-II superconductors, where increasing vortex density drives transitions from ordered Abrikosov lattices to disordered regimes. We propose a falsifiable bridge: DOFT’s coherence observable may behave like a correlation-length proxy in a disordered elastic medium, making the observed exponent (~1/3) plausibly comparable to collective-pinning scaling regimes discussed in the vortex literature. We emphasize this correspondence as a testable hypothesis, not an identification.

**Keywords:** delayed oscillators, coherence scaling, topology selection, memory layer, structural ceiling, vortex lattice, collective pinning, Abrikosov lattice, phase transition, order–disorder transition

## 1. Motivation and context (what Paper 3 adds)

DOFT inverts the usual modeling direction: instead of starting from microscopic Hamiltonians, it starts from constraints—delayed coupling, finite memory, and lock formation in oscillator networks—and asks what stable structure is permitted.

**Paper 1 (superconductors datasets):** prime-space fingerprints derived from a delayed-locking grammar plus a minimal correction law, suggesting low-parameter constraints can produce discrete stable signatures in superconducting materials.  
**Paper 2 (superconductors datasets):** integer-participation structure under structural noise using a mother-frequency observable, emphasizing discrete structure and robustness to noise in the same material class.

**This Paper 3 (DOFT-only mechanism):** isolates the DOFT dynamics in a controlled simulation pipeline to answer:

> What is the intrinsic cost of increasing N in DOFT networks, and what mechanism allows coherent structure to persist as complexity increases?

We focus on interpretation-light observables: coherence, memory participation, and topology-conditioned survival. A conservative, testable bridge to vortex matter is proposed in Discussion.

---

## 2. The Ola pipeline (Ola1 → Ola4) in one page

The program proceeds in olas designed to extend scale while preserving comparability.

**Ola1 (baseline, Appendix A):** defines the internal scaffold (Q1/S1/S2), lock vocabulary, and produces a transferable “block” library by a deterministic seeded sweep (reproducible per run).

**Ola2–Ola4:** implement a search-and-hunt + verification split for tractability at larger N:

- **Explorer (fast)** proposes candidate networks from configurable topology templates and the prior block library (cheap screening).
- **Sweep (high-fidelity)** integrates the coupled differential dynamics for each candidate and computes late-time observables (this stage produces the paper numbers).

**Recursive state transfer.** Ola k+1 consumes promoted blocks from Ola k (see Appendix A for file-level details: `simple_blocks.json` + `dof_dna_catalog.csv`).

**Why the split matters.** Explorer controls tractability; Sweep controls truth. The paper’s quantitative observables are always computed from Sweep outputs, not from Explorer heuristics.

## 3. Definitions and observables (operational)

### 3.1 Coherence / lock strength R
We quantify global coherence using a lock-strength statistic **R ∈ [0, 1]** computed from late-time behavior under Sweep dynamics (e.g., last-window mean). Larger R indicates stronger coherent locking across the network.

**Important:** all reported R values are Sweep outputs from differential dynamics integration. Explorer does not “generate coherence”; it selects which candidates are evaluated.

### 3.2 Memory participation (S2)
We quantify “memory” as participation of an internal memory layer **S2**, reported as **S2-share** (normalized contribution of S2 in stabilized outcomes). This is treated as an operational DOFT observable (not an ontological claim).

### 3.3 Topology and template classes
Each run is associated with a topology template (ring/ladder/bipartite/complete/…) and its structural class (e.g., “monolithic” vs “bipartite”). We use template-conditioned comparisons to isolate topology effects at fixed N.

*(Selection grades and threshold sensitivity are treated as controls and are summarized in Appendix C rather than driving the main narrative.)*

## 5. Discussion

### 5.1 Why “−1/3” is the right kind of claim (and what we do not claim)
We claim robust monotone decay of coherence with N, and we report that within the explored range the best-fit power law yields an exponent near −1/3. We do not claim that −1/3 is uniquely determined from first principles here, nor that it holds indefinitely beyond the explored range. The value of the exponent is that it makes the phenomenon compressible and testable.

### 5.2 Memory is not decoration: it is the scaling mechanism (or it isn’t)
The S2 result upgrades “memory” from vocabulary to a measurable scaling mechanism: survival at larger N is associated with elevated memory participation. The mechanism claim is deliberately modest: S2 behaves like an overhead channel that becomes engaged under geometric stress, consistent with a “metabolic cost” framing. Appendix C provides a regime-change diagnostic that complements this picture.

### 5.3 Why this matters for a superconductors-heavy audience (Papers 1–2 continuity)
Paper 3 provides the mechanistic “source behavior” for the discrete signatures emphasized in Papers 1–2: rather than extracting structure from external datasets, we show that the DOFT dynamics itself produces scaling constraints, topology selectivity, and regime transitions. This keeps the narrative anchored in testable computational behavior while still speaking to condensed-matter intuitions.

### 5.4 Vortex matter as a physical testbed (speculative, but falsifiable)

#### 5.4.1 A controlled mapping (hypothesis)
We propose a conservative mapping as a testable hypothesis:

- **N** ↔ effective vortex density (monotone with magnetic field **H**)
- **R** ↔ correlation / coherence scale (order-parameter or correlation-length proxy, depending on probe)
- **S2-share** ↔ disorder/pinning overhead required to sustain residual coherence
- topology selectivity ↔ geometry constraints becoming non-degenerate at higher density
- monolithic ceiling ↔ loss of viability of single-domain coherence beyond a critical density

This mapping asserts a structural analogy with measurable predictions; it does not claim a microscopic identity.

#### 5.4.2 The Larkin–Ovchinnikov bridge (responsible statement)
Collective pinning theory (Larkin–Ovchinnikov) predicts that correlated domain size / correlation length decreases with field:

> **R_c ∝ H^(−α)**

Reported α depends on regime and dimensionality; layered or quasi-2D contexts often show α in the ~0.3–0.4 neighborhood (regime-dependent), numerically overlapping 1/3. What we can responsibly say now is:

- DOFT produces **R ∝ N^(−1/3)** over the explored range,
- LO-type frameworks produce **R_c ∝ H^(−α)** with comparable α in some regimes,
- therefore it is plausible (not proven) that DOFT’s R behaves like a correlation-length proxy under an H↔N monotone mapping, making the exponent overlap an empirical target.

#### 5.4.3 Concrete falsifiable predictions (minimal set)
- **Scaling interface:** in selected vortex regimes, a correlation-length proxy should decay with field; testing whether α ≈ 1/3 is plausible in that regime becomes a direct comparison target.
- **Ceiling interpretation:** the monolithic ceiling suggests a sharp transition where single-domain coherence fails; the vortex analog is where correlation length approaches a microscopic scale (vortex spacing or pinning length).
- **Pinning overhead:** if S2 is analogous to pinning overhead, disorder-mediated stabilization should grow in importance as density increases in regimes where residual order survives.
- **Geometry selectivity:** anisotropic/layered materials should exhibit stronger sensitivity to symmetry/constraints at higher fields, consistent with topology becoming selectively constraining at larger N.

### 5.5 Limitations and controls (must be explicit)
- **Threshold tightening is a confound:** thresholds vary by ola for tractability. We therefore emphasize template-conditioned comparisons and provide a regime-change diagnostic in Appendix C.
- **Finite template vocabulary:** topology selectivity is defined relative to the template set; expanding templates can change which topologies look privileged, though the existence of increasing selectivity with N remains the claim.
- **N range is limited in current runs:** we report within the explored range and avoid asymptotic claims.
- **Superconductors bridge is a hypothesis:** presented to be test-anchored, not identity-anchored.

## 6. Conclusion
Using a DOFT-only Explorer+Sweep program across Ola1–Ola4, we report: (1) coherence decays monotonically with network size, consistent over the explored range with R ∝ N^(−1/3); (2) larger-N survival is associated with elevated S2 participation, consistent with memory acting as stability overhead under geometric stress; and (3) topology becomes increasingly selective with N, with an apparent monolithic ceiling around N ≈ 8–9 for single-module templates.

We propose a conservative, falsifiable bridge to vortex matter in type-II superconductors: DOFT’s coherence scaling may serve as a correlation-length proxy analog under a monotone H↔N mapping, making the exponent overlap with collective-pinning regimes a direct experimental comparison target.

# Appendix A — Ola1 baseline (one-page minimal spec)

## A.1 Why Ola1 exists (baseline constraints)
Ola1 defines the baseline DOFT scaffold used throughout the pipeline. Its purpose is not to validate a specific physical mapping, but to operationalize a minimal internal vocabulary and produce a transferable state for later stages.

Ola1 establishes:
- a three-component internal scaffold (Q1/S1/S2, where S2 acts as the memory/delay interface) used as the initial layer model;
- the operational notion of locks and late-time coherence observables computed from differential dynamics integration;
- the initial “block” representation that later olas will rehydrate into higher-N candidates.

## A.2 Ola1 procedure (deterministic seeded random sweep)
Ola1 is executed as a deterministic seeded sweep: each run is defined by an explicit seed, and that seed deterministically selects a parameter instance (“RNG per-run”). The run then integrates the coupled differential dynamics and measures late-time observables (including R) over a standardized window.

In practice:
- Seed → parameter instance: per-run deterministic sampling (reproducible).
- Dynamics integration: coupled differential dynamics (ODE / delay-ODE depending on configuration).
- Late-time measurement: compute coherence/lock statistics (e.g., last-window mean) and record internal participation metrics (including S2-share).

## A.3 What transfers from Ola1 into Ola2…N (promoted block state)
The pipeline is recursive: Ola k+1 consumes the promoted blocks produced by Ola k. The transferable state exported from each ola (including Ola1) is:

### simple_blocks.json
A promoted block library containing internal state variables needed for rehydration (e.g., phase/state history buffers and internal coordinates stored in theta_internal), a reference frequency (omega_ref), and associated descriptors.

### dof_dna_catalog.csv
A compact “DOF DNA” catalog providing gene summaries (genes_min) and metadata: schema_version, block_id, dof_grade, dof_family_id / dof_family_friendly, plus provenance (hashes + run information).

Together these define the rehydration substrate: later olas assemble multi-node candidate networks by composing prior promoted blocks (structure from simple_blocks.json) under constraints and metadata in dof_dna_catalog.csv.

## A.4 How Ola2…N differs from Ola1 (why the Explorer exists)
From Ola2 onward, the pipeline remains ODE-based for measurement but becomes tractable via a split:

- Explorer (fast search-and-hunt): proposes candidate network instances from topology templates and block libraries (cheap screening).
- Sweep (high-fidelity verification): integrates ODE dynamics for each candidate and computes late-time observables.

Unlike Ola1, Ola2…N sweeps do not randomize parameters per run: the Sweep evaluates specific candidates proposed by the Explorer.  
This split is computational: it allows scaling to larger N while keeping reported observables grounded in the same differential-dynamics measurement stage.
